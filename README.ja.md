## 🎮 ゲーム概要

**Multiples-Of-Three（3の倍数ゲーム）** は、4×4の16マスにランダムに表示される数字（1〜300）の中から「3の倍数」を素早く見つけて消去していくパズルゲームです。

マス目の数字と配色は3秒ごとに再配置（リフレッシュ）されます。素早く3の倍数をタップしてロックし、「Clear」ボタンでまとめて消去していきましょう！消去したマスの奥からは、月替わりの美しい花のイラストが現れます。

#### 🎨 カラーユニバーサルデザイン（CUD）への配慮

*外部リンク カラーユニバーサルデザイン（CUD）とは*: [特定非営利活動法人 カラーユニバーサルデザイン機構 CUDO](https://cudo.jp/?page_id=74)

多様な色覚を持つすべてのユーザーが見分けやすいよう、日本のCUD推奨配色セットに基づいた色設計を採用しています：
- 空色 (`#bfe4ff`)
- クリーム色 (`#ffff80`)
- 明るいピンク (`#ffcabf`)
- 薄緑色 (`#77d9a8`)

背景色に対して文字は高コントラストな濃い色（`#111111`）で統一し、誰でもストレスなく識別できるように配慮されています。

## 🕹️ 遊び方

1. **ゲーム開始**: 「Start」ボタンをタップすると3秒のカウントダウン後、59秒の制限時間がスタートします。
2. **3の倍数を見つけてタップ**: 3の倍数（例: 3, 12, 45, 99, 150 など）をタップします。
   - タップしたマスは「ロック状態」となり、3秒ごとの数値更新から除外されます。
   - ※ロックされたマスは通常マスと見た目が変わりません。自分の記憶を頼りにプレイしてください！
3. **まとめて消去（Clear）**: 「Clear」ボタンをタップすると、ロックしたマスを一度に消去できます。
   - 消去されたマスは半透明になり、背後のイラストが見えるようになります。
4. **クリア条件**: 制限時間（59秒）以内に16マスすべてを消去するとゲームクリアです！

## 🏆 スコア計算ルール

### ➕ 加点ルール

クリアしたマスに表示されていた番号がSCOREに加算されます。

* **同時消しボーナス（Clearボタン）**:
  3マス以上を同時にクリアすると、指数関数的なボーナススコアが加算されます（四捨五入して整数値）：
  $$\text{加算スコア} = \text{round}\left( (\text{消去したマスの数値合計}) \times 1.01^{N - 2} \right)$$
  - **1枚消去時**: 1.0倍（等倍：ボーナスなし）
  - **2枚消去時**: 1.0倍（等倍：ボーナスなし）
  - **3枚同時消去時**: **1.01倍**
  - **4枚同時消去時**: **1.0201倍**（1.01の2乗）
  - **5枚同時消去時**: **約1.0303倍**（1.01の3乗）
  - *(以降、同時消し枚数に応じて増加)*


* **残り時間ボーナス（タイムボーナス）**:
  制限時間内に全消去クリア（またはStrikes上限でゲーム終了）した場合、残り時間1秒につき **51点** のボーナスがスコアに加算されます：
  $$\text{タイムボーナス} = \text{残り秒数} \times 51$$

---

### ➖ 減点＆Strikes（ミス）ルール

* **3の倍数ではないマスをタップ**:
  - そのマスの数値がスコアから**減算**されます。
  - **Strikes（ミス）が +1** されます。
* **すでにロックされているマスを再タップ**:
  - そのマスの数値がスコアから**減算**されます。
  - **Strikes（ミス）が +1** されます。
* **Strikes上限**:
  - **6回ミス（6 Strikes）**すると、その時点でゲームオーバーとなります（残り時間ボーナスは加算されます）。
